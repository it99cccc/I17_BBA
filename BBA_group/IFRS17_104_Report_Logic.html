IFRS17 104 报表计算逻辑说明文档

1. 报表概述与列定义

104 报表（未到期责任负债调节表）按计量单元拆分负债构成，展示从期初到期末的变动来源。

列名 代码字段 符号逻辑 (Display Sign)
未来现金流量的现值
(BEL / PV)		 pv
  • 负债增加：正数 (+)
  • 负债减少/释放：负数 (-)
  • 包含盈利合同和亏损合同的预期现金流现值。
非金融风险调整
(RA)		 ra
  • 负债增加：正数 (+)
  • 负债减少/释放：负数 (-)
合同服务边际
(CSM)		 csm
  • 负债增加（未赚利润增加）：正数 (+)
  • 负债减少（摊销/转回）：负数 (-)

2. 详细行计算逻辑拆解

以下逻辑基于代码文件 generate_ifrs17_104_report.py 分析得出。

项目 (Row) 计算公式与代码逻辑 逻辑说明
(1) 年初的保险合同负债
PV = opening_balance['pv']
RA = opening_balance['ra']
CSM = opening_balance['csm']
 直接读取上一年度期末余额。
(4) 合同服务边际的摊销
CSM = get_d('保险合同收入_摊销的CSM')
通常为负数 (减少负债) 		CSM 随服务提供而摊销确认为收入，导致 CSM 余额减少。
(5) 非金融风险调整的变动
RA = -get_d('保险合同收入_预期释放的非金融风险调整_含亏损')
 取反操作：日志中“释放”通常记录为正值（代表释放量），报表中需显示为负债减少（负数）。
使用含亏损总额，不重复计算亏损分摊。
(6) 当期经验调整
PV = 0(实际) - 预期赔付(含亏损) + 经验调整(log)
 反映当期预期现金流的释放（减少负债）以及与实际发生的差异。
注：此处实际赔付设为0，是因为LIC变动在Row 13反映，此处仅关注LRC的释放。
(8) 当期初始确认的保险合同影响
PV = (新单赔付+费用-保费)_盈利 + (新单赔付+费用-保费)_亏损
RA = 新单RA_盈利 + 新单RA_亏损
CSM = 新单CSM_盈利
 汇总所有新签保单的影响。
盈利合同产生 CSM，亏损合同不产生 CSM (确认为亏损成分)。
(9) 调整合同服务边际的估计变更
PV = -get_d('未到期_调整CSM的预期现金流变动')
RA = -get_d('未到期_调整CSM的非金融风险调整变动')
CSM = get_d('未到期_调整CSM的估计变更')
 核心逻辑：
1. 只有浮动收费法(VFA)或一般模型下未来现金流变动才调整 CSM。
2. 符号取反：如果预期现金流增加（PV +），则 CSM 应减少以吸收该损失（CSM -）。为保持行内平衡，PV/RA 显示为 CSM 的对冲方向。
(10) 不调整合同服务边际的估计变更
PV = -get_d('亏损合同损益_不调整CSM的预期现金流变动')
RA = -get_d('亏损合同损益_不调整CSM的非金融风险调整变动')
CSM = 0
 当合同为亏损状态（无 CSM 可吸收）时，现金流变动直接计入当期损益。
日志字段为“损益影响”（负数代表亏损/负债增加），报表 PV 列取反后变正数（负债增加）。
(17) 保险合同金融变动额 (IFIE)
PV = IFIE_P&L_CF (非亏损+亏损)
RA = IFIE_P&L_RA (非亏损+亏损)
CSM = -get_d('IFIE_P&L_未到期_CSM')
 包含利息计提（Accretion of Interest）。
CSM 利息计提在日志中记为费用（负数），报表中需显示为负债增加（正数），故取反。
(19) 其他综合收益其他变动 (OCI)
PV/RA = IFIE_OCI (非亏损+亏损)
 反映折现率变动对负债的影响。
(25) 现金流量合计
PV = 收到保费 + 支付费用
 收到保费增加 PV 负债（正数）；支付费用减少 PV 负债（负数）。
仅影响 PV 列，不影响 RA 和 CSM。
