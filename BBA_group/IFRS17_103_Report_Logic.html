IFRS17 103 报表计算逻辑说明文档

1. 报表列定义与符号规则

本报表用于展示保险合同负债的期初至期末的调节过程（Roll-forward）。

列名 含义 符号逻辑 (Display Sign)
LRC-非亏损部分
(LRC Non-LC)		 未到期责任负债 - 正常盈利部分
  • 负债增加：正数 (+)
  • 负债减少/收入：负数 (-)
  • 计算逻辑：通常通过 Total - LC 倒挤得出
LRC-亏损部分
(LRC LC)		 未到期责任负债 - 亏损成分 (Loss Component)
  • 负债余额：正数 (+) (尽管在底层数据中可能存储为负值，但在报表中展示为绝对值)
  • 亏损确认(增加LC)：正数 (+)
  • 亏损释放(减少LC)：负数 (-)
已发生赔款负债
(LIC)		 已发生但未支付的赔款负债
  • 负债增加：正数 (+)
  • 支付赔款：通常减少负债

2. 各行项目详细计算逻辑

项目 (Row) 计算逻辑 / 公式 备注
(1) 年初的保险合同负债
Opening Balance
LRC-LC = abs(期初LC余额)
LRC-Non-LC = 期初总LRC - LRC-LC
来源于上一年度期末余额。非亏损部分通过倒挤计算，以确保总额平衡。
(4) 保险服务收入合计
Insurance Revenue
收入 = CSM摊销 + IACF摊销 + 经验调整 - 预期赔付释放 - RA释放

  • CSM/IACF摊销：负值 (减少负债)
  • 预期赔付/RA释放：取负号 (减少负债)
收入主要体现在 LRC-非亏损 列。LRC-亏损列收入为0。
(10) 保险服务费用
Insurance Service Expenses
费用 = (6)IACF摊销 + (7)亏损确认及转回 + (8)LIC变动
费用增加负债 (正数)。
  ↳ (6) IACF摊销
LRC-Non-LC = 摊销金额
增加 LRC-非亏损 部分。
  ↳ (7) 亏损部分的确认及转回
Loss Component Recog.
LRC-LC = 初始确认亏损 + 现金流变动 + RA变动 - LC释放
LRC-Non-LC = 0
关键逻辑：
1. 初始确认和不利变动增加 LC (正数)。
2. LC释放 (分摊) 减少 LC (负数)。
3. 净额记入 LRC-亏损 列。
(11) 保险服务业绩
Insurance Service Result
(11) = (4)收入 + (10)费用
反映承保利润。
(12) 保险合同金融变动额
IFIE (P&L)
LRC-LC = abs(IFIE_LC) * (-1 if negative impact)
LRC-Non-LC = Total_IFIE - LRC-LC
包含利息计提。LC列增加负债为正，减少为负。
(14) 其他综合收益其他变动
OCI
LRC-LC = abs(OCI_LC) * (-1 if negative impact)
LRC-Non-LC = Total_OCI - LRC-LC
反映折现率变动影响。
(21) 现金流量合计
Cash Flows
CF = 收到保费(正) + 支付费用(负)
主要影响 LRC-非亏损 列。收到保费增加负债，支付费用减少负债。
(23) 年末的保险合同净负债
Closing Balance
期末 = 期初(1) + 业绩(11) + 金融变动(12) + OCI(14) + 现金流(21)
严格遵循滚算逻辑。LRC-亏损列显示为绝对值。

3. 年末 LRC-亏损 (Loss Component) 动态变动示意图

下图展示了 LRC-亏损部分 (Loss Component) 从年初到年末的变动逻辑：

1. 年初余额 (Opening LC) = 上年末余额 (绝对值)
代表期初已确认的亏损责任
↓
2. 本期新确认亏损 (New Loss Recognized) + 初始确认亏损 (Initial Recognition)
新签亏损保单带来的亏损
↓
3. 假设/变动调整 (Changes in Estimates) + 预期现金流不利变动
+ 非金融风险调整(RA)不利变动
未来现金流增加导致亏损增加
↓
4. 亏损释放/分摊 (LC Release) - 预期赔付与费用的亏损分摊
- RA释放的亏损分摊
随着服务提供，亏损责任逐渐释放（转回）
↓
5. 金融变动 (IFIE & OCI) + 利息计提 (Accretion of Interest)
时间价值导致的负债增加
↓
6. 年末余额 (Closing LC) = (1) + (2) + (3) - (4) + (5)
最终的年末亏损成分余额
